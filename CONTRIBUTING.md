# Trabalho em equipe

1. Escolher uma tarefa no plano e registrar responsável no GitHub.
2. Criar branch: `feat/metricas`, `feat/agente-rag`, `feat/rede-cortes`, `feat/interface` ou `chore/mlops`.
3. Fazer commits pequenos; abrir PR explicando comportamento, validação e limitações.
4. Pedir revisão de outro integrante antes do merge. Esta é uma convenção, não uma proteção de branch já configurada.
5. Atualizar documentação e configurações junto ao código. Não registrar métricas fictícias como resultados.
6. Não versionar vídeos, frames extraídos, PDFs restritos, chaves, pesos ou índices vetoriais.

O formato compartilhado está em `docs/ARQUITETURA.md`. Se mudar, alinhar as duas frentes no mesmo PR. Não preencher funcionalidades ausentes com zeros.
