# Base de conhecimento

Versionar `sources.csv` com DOI/URL e metadados. PDFs locais em `documents/` e índice em `index/` são ignorados. Só redistribuir documentos quando a licença permitir.

Na ingestão, preservar fonte, página/seção, contexto, população estudada e limitações. Conferir texto extraído de tabelas. Validar manualmente trechos usados pelo agente. Fontes iniciais são candidatas: não foram ingeridas ou validadas nesta estrutura.
